# Py NC converter
## Предназначение
Утилита предназначена для конвертации кода фрезерных ЧПУ программ из Fanuc в Syntec. И наоборот.
В 1С грузится код Syntec, иногда для цеха требуется код Fanuc для непосредственной загрузки на станок (без выгрузки из 1С). В таком случае требовалось найти и открыть проект, вывести все программы другим постпроцессором и полученные файлы передать цеху.
Данная утилита позволяет на лету создавать конвертированные файлы, не открывая проект.

## Как пользоваться
Находясь в нужной папке с программами, запустить через тотал коммандер файл nc_converter.exe.
Программа найдет все файлы с именами на o6..., O6..., o7..., O7... .
Далее программа сама определит тип каждой программы (Fanuc или Syntec) и конвертирует текст файлов.

Для новых конвертированных файлов Fanuc будет создана директория
    converted to fanuc
Для новых конвертированных файлов Syntec будет создана директория
    converted to syntec

Изначальные файлы не модифицируются.

## Как разрабатывать новую версию
1. активировать git
2. перейти на ветку dev
3. дописать функционал
4. протестировать первично, доработать
5. сделать коммит, описав изменения
6. оттестировать в рабочей среде
7. сделать git merge в main

## Как билдить новые exe
1. открыть VScode
2. октрыть проект
3. открыть терминал в корне проекта
4. активировать виртуальное окружение
5. открыть второй терминал
6. перейти в директорию для сборки приложения

```bash
cd build_dir/
```

7. запустить процесс сборки exe

```bash
pyinstaller --onefile ../src/nc_converter/nc_converter.py
```

8. положить новый exe из папки build_dir/dist в 

```
w:\ROBOCOPY\sharing\CREO8_START_NC\ПОЛЕЗНОСТИ\
```

9. описать проделанные изменения в 

```
w:\ROBOCOPY\sharing\sharing_CHANGELOG.txt
```
